# 비즈니스 영어 콘텐츠 확장 파이프라인

## 현재 상태와 목표

2026-11-06 기준 기본 팩 126개와 첫 비즈니스 핵심 팩 59개, 총 **185개 단어·표현**이 코드에 포함돼 있다. 이 중 **113개**에 구어체·문어체 비교 예문과 한국어 용법 메모가 있고, 새 팩의 **12개**에 유의어 뉘앙스가 있다. 모든 항목에는 영어 예문과 한국어 번역이 있다. 검증된 출처가 있는 어원 항목은 아직 없다. 수량은 `packages/content/test/content.test.mjs`의 검증값이다.

선택한 확장 방식은 **선정 → AI 초안 → 검수 → 버전별 배포**다. 2,500–3,000개를 한 번에 생성하거나 공개하지 않는다. 목표치는 *서로 다른 학습 항목* 기준이며 단어와 다단어 표현을 모두 포함한다. 출시 단계별 누적 목표는 ① 약 300개, ② 약 800개, ③ 약 1,600개, ④ 2,500–3,000개다. 현재 185개다. 각 단계는 사용 빈도와 활용 상황을 먼저 검증한 뒤 확장한다. 목표 수량은 검수 완료를 뜻하지 않으며, 실제 공개 수량은 검수 통과 항목만 센다.

우선순위는 회의·의견 조율, 이메일·메신저, 고객 응대, 발표·보고, 협상·거절, 프로젝트 일정·문제 해결, 채용·면접, 재무·계약이다. 핵심 동사와 결합어(*follow up on*, *raise a concern*) 및 문장 틀을 단일 고급 명사보다 우선한다. 기존 항목과 의미가 중복되거나 문맥이 희귀한 표현은 제외한다. 사용자가 자주 틀리거나 말하기에서 실제로 쓰려 한 표현은 다음 검수 팩의 후보로 삼되, 개인 대화 내용을 공개 콘텐츠에 자동 편입하지 않는다.

## 항목 제작과 검수

각 후보에는 안정적인 ID, 표제형, 품사, 하나의 명확한 뜻, 한국어 풀이, CEFR **추정** 수준, 실무 상황, 자연스러운 영어 예문과 정확한 한국어 번역을 만든다. 필요한 경우 구어체·문어체 대안, 두 표현의 사용 차이, 유의어와 뉘앙스, 어원을 추가한다. 어원은 신뢰할 수 있는 근거가 있을 때만 넣는다. 빈 항목을 AI 추측으로 채우지 않는다. CEFR은 단어 자체의 공인 등급이라고 주장하지 않고 학습 난이도 라벨로 다룬다.

AI는 초안 작성 도구다. 초안은 별도 staging 파일에만 저장하고, 검수자 승인 없이 앱에 자동 게시하지 않는다. 배치별로 프롬프트·모델·날짜·후보 출처·검수자를 기록한다. 검수 체크리스트:

- 표제형·품사·뜻이 같은 문맥에서 맞는지, 다의어를 잘못 섞지 않았는지 확인한다.
- 영어 예문이 자연스럽고 업무 상황에 실제로 쓸 만한지 확인한다. 원어민스럽지 않은 과잉 격식과 유행어를 걸러낸다.
- 한국어 번역이 의미·말투·시제를 보존하는지 확인한다.
- 구어체와 문어체가 같은 의도를 표현하며, 상황별 격식 차이를 설명하는지 확인한다.
- 유의어가 해당 **뜻**의 대체어인지 확인하고 완전 동의어처럼 보이게 하지 않는다.
- 어원은 출처를 확인하고, 불확실하면 삭제한다.
- CEFR 추정 수준과 업무 주제가 학습 순서에 맞는지 확인한다.
- 기존 항목과 뜻·예문의 중복, 상표·고유명사, 민감정보, 저작권이 있는 문장 복제를 점검한다.
- 자동 검증으로 필수 필드·ID 중복·길이·레벨 값·번역 누락·구어체/문어체 쌍 누락을 검사한다.

첫 `business-core` 팩은 B1–C1 실무 표현 59개다. 회의·일정·업무 인계·고객 응대·협상·재무 맥락을 포함한다. 59개 모두 영어·한국어 예문, 구어체·문어체 예문과 용법 메모를 갖고 있으며, 12개에는 유의어 뉘앙스가 있다. 구조·중복·예문 포함 여부는 자동 검증을 통과했다. 실제 업무 영어 자연스러움은 배포 후에도 교정할 수 있도록 팩 버전과 안정적인 항목 ID를 유지한다.

## 출처와 권리 정책

표제어 후보 선정에 공개 자료를 참고할 수 있지만, 타사 학습 앱의 단어 목록·설명·예문·화면을 복사하지 않는다. 앱에 게시하는 설명과 예문은 자체 작성하거나 라이선스가 허용하는 자료만 사용한다. 단어 자체는 자유롭게 사용할 수 있어도 사전의 뜻풀이·예문·어원 설명은 저작권이 있을 수 있다. 외부 자료에서 실제 내용을 가져오면 항목 단위로 원본 URL, 라이선스 버전, 저작자·표시 문구, 수정 여부를 보존하고 배포 조건을 검토한다. 이를 저장·표시할 방법이 없다면 해당 자료를 가져오지 않는다.

검토한 자료:

- [Princeton WordNet의 라이선스와 상업적 사용 안내](https://wordnet.princeton.edu/license-and-commercial-use): 라이선스 조건하에 상업적 사용이 가능하다고 안내한다. 유의어 **후보**에 유용하지만 뜻 구분, 한국어, CEFR, 업무 격식은 별도 검수가 필요하다. 사용 시 원문 라이선스를 배포본에 포함하고 요구되는 표시를 따른다.
- [Wiktionary 저작권 정책](https://en.wiktionary.org/wiki/Wiktionary:Copyrights): 원문은 CC BY-SA 4.0과 GFDL 이중 라이선스다. 직접 가져오면 저작자 표시·동일조건공유 등의 의무를 검토해야 하므로 현재 팩에는 가져오지 않는다.
- [Tatoeba 이용 조건](https://tatoeba.org/en/terms_of_use): 문장의 기본 라이선스는 CC BY 2.0 FR이며 저작자 표시가 필요하다. 음성은 조건이 다를 수 있다. 현재 팩에는 문장·음성을 가져오지 않는다.

사용자가 자신의 문서·단어를 가져오는 기능을 추가하더라도 기본 공개 팩과 분리하고 개인 저장소에만 둔다. 사용자의 자료를 다른 이용자에게 재배포하거나 AI 학습용으로 사용하지 않는다. 외부 자료와 AI 초안의 사실성·권리 검토는 게시 전 필수다.
