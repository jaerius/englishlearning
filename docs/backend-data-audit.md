# 학습 기록 계산 검수

2026-11-04 기준 서버 API를 코드와 자동 테스트로 확인했다. 브라우저에 하드코딩되어 있던 7일 연속 학습, 82% 정답률, 오답 2개 등은 실제 기록이 아니며 서버가 만든 값도 아니다. 서버의 빈 데이터베이스는 학습·오답·연속 일수를 모두 0으로 반환한다.

| 수치 | 실제 계산 기준 |
| --- | --- |
| 연속 학습 | 한국 시간 날짜별로 단어를 1개 이상 학습한 날을 센다. 오늘 기록이 없으면 어제부터 역산한다. 빈 세션은 세지 않는다. |
| 최근 7일 정답률 | 오늘을 포함한 한국 시간 최근 7개 날짜의 첫 시도 정답 수 ÷ 학습 단어 수. 기록이 없으면 0%다. 이전 구현은 가장 최근 *기록된* 7일을 가져와 오래된 학습을 포함하는 오류가 있었다. |
| 암기 단어 | 기획서에 따라 SRS `stage >= 4`인 사용자 단어 수다. |
| 복습 예정 | 다음 복습일이 오늘 이전 또는 오늘인 사용자 단어 수다. |
| 오답노트 | 기획서 계약인 `wrongCount > 0 && stage < 4`를 따른다. 따라서 한 번 틀린 단어는 나중에 맞혀도 stage 4에 도달하기 전까지 남을 수 있다. 초기 계정에는 0개다. |

`GET /api/stats/coach`는 최근 30일 첫 답안만 사용해 CEFR 수준·품사별 시도 수, 오답 수, 힌트 수, 정답률을 반환한다. 두 번 미만 시도한 묶음은 약점 순위에 올리지 않고, 전체 첫 시도 5개 미만이면 `insufficientData: true`를 반환한다. 종료한 말하기 세션의 최근 교정문 최대 3개도 실제 저장 기록에서 함께 반환한다. 이것은 관측된 학습 패턴 요약이며 AI 교사의 종합 진단이라고 주장하지 않는다. 실제 AI 교정 품질을 평가하려면 말하기 공급자와 기기 테스트가 추가로 필요하다.

서버 테스트는 빈 계정의 모든 지표가 0인지, 오래된 날짜가 7일 정답률에 섞이지 않는지, 빈 세션이 연속 학습을 올리지 않는지, 오답 재도전이 약점 통계에 중복되지 않는지 검증한다.
