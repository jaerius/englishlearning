# 영어 학습 앱 제품 명세

이 문서는 제공된 19쪽짜리 개인용 영어 학습 앱 기획서를 구현 가능한 기준으로 정리한 것이다. 2026-11-04 사용자 피드백을 반영해 가짜 기록 제거, 서버 없이 실제 단어 학습, CEFR A1–C2, 비즈니스 영어 비교, 맞춤형 약점 피드백을 우선한다.

## 1. 제품 목표와 경계

- 한 줄 정의: 하루 10분 동안 수준에 맞는 단어를 학습하고, 오늘 배운 단어를 AI 대화에서 직접 사용하는 개인용 영어 학습 PWA.
- 사용자: 본인 한 명. 앱 로그인·결제·소셜·리그·랭킹은 없다.
- 클라이언트: React + Vite + TypeScript PWA. iPhone Safari 375~430px와 홈 화면 설치를 지원한다.
- 서버: 본인 Mac mini에서 상시 실행하는 NestJS API + SQLite 파일 DB. 웹 앱은 Vercel에서 정적으로 배포한다.
- 접속: iPhone에서 Vercel 웹 앱을 열고 Tailscale `serve` HTTPS로 Mac mini API에 접속한다. Funnel·포트 포워딩으로 API를 공개하지 않는다. 서버가 없을 때 단어 학습 기록은 기기에 저장하며 현재 서버 기록과 자동 병합되지 않는다.
- 핵심 루프: 오늘의 학습 → 새 단어 카드 → 단계별 퀴즈 → 결과·오답 복습 → 연속 학습일 갱신.
- 차별점: 오늘 학습한 단어를 말하기 세션의 목표 단어로 주고, 교정 없이 정확히 사용한 단어를 SRS에 정답 1회로 반영한다.
- 성공 기준: 30일 연속 학습, 일평균 학습 시간 10분 이하.
- 비용 한도: 이전 사용자 요청을 우선해 API 비용 월 KRW 5,000 미만을 목표로 한다. 서버가 일일·월간 AI 사용량과 추정 예산 한도를 강제한다. Mac mini 전기료는 실측 전이다.

### 비목표

- 회원가입, 결제, 소셜, 리그, 랭킹, 푸시, 위젯.
- 문법·듣기 전용 코스, 발음 점수, 앱스토어·네이티브 앱.
- Speak·말해보카의 코드, 브랜드, 문구, 이미지, 단어장 복제.

## 2. 정보 구조와 이동

하단 탭은 `학습(S4) / 말하기(S10) / 내 기록(S14)` 세 개다. 레벨 테스트, 학습 세션, 대화 세션 중에는 탭을 숨긴다.

```text
첫 실행  S1 → S2 → S3 → S4
학습     S4 → S5 → S6 → S7 → S4
복습     S4 → S6 → S7 → S4
오답     S4/S14 → S8 → S9 또는 S6
말하기   S10 → S12 → S13 → S10
사용자 상황 S10 → S11 → S12
기록     S14 → S8/S15
```

## 3. 화면 명세

### S1 레벨 테스트 인트로

- 최초 실행 시 `settings.user_level`이 없으면 자동 표시한다. 설정에서 다시 진입할 수 있다.
- 캐릭터, `내 수준 알아보기`, `24문제 · 약 4분`, 하단 고정 `시작하기`, `나중에 할게요`를 표시한다.
- 건너뛰면 레벨 1을 저장하고 S4로 이동한다.

### S2 레벨 테스트 문제

- CEFR A1–C2 여섯 레벨에서 각 4문항씩, 총 24문항을 낸다. B1/B2부터 시작해 난이도를 섞고 정답 위치를 네 칸에 균형 배치한다.
- 진행바, `n/24`, 종료 X, 단어와 듣기, 4개 한국어 뜻 보기, `모르겠어요`를 제공한다.
- 선택 시 정답을 공개하지 않고 0.2초 하이라이트 후 다음 문제로 간다. 중단 시 처음부터 다시 시작한다는 확인창을 띄운다.
- 레벨별 단어 4개를 무작위 추출하고 오답 3개는 같은 레벨에서 고른다.
- 로딩 스켈레톤, 오류·재시도 상태가 있어야 한다.

### S3 레벨 테스트 결과

- CEFR 임시 어휘 수준, 레벨별 정답 수 막대 6개, `학습 시작하기`를 표시한다. IELTS 점수를 이 어휘 테스트로 추정하지 않는다.
- 레벨별 4문항 중 3개 이상 맞힌 가장 높은 레벨을 결과로 한다. 없으면 레벨 1이다.
- 시작 버튼에서 레벨을 저장하고 S4로 이동한다.

### S4 학습 홈

- 상단 연속 학습일과 설정, 오늘 목표 링, `오늘 학습 시작` 또는 `더 학습하기`, 같은 비중의 복습 카드, 오답노트 행을 표시한다.
- 복습은 최대 `review_cap`만 표시·출제한다. 복습 0개면 `복습 끝!` 상태다.
- 일일 세션은 복습 대상 후 새 단어를 선택하며, 새 단어가 있으면 S5, 없으면 S6으로 간다.

### S5 새 단어 카드

- 새 단어 기본 10개를 퀴즈 전에 본다. 진행바·종료 X와 한 장씩 표시한다.
- 앞면: 단어, 품사, 듣기. 뒷면: 뜻, 단어가 강조된 영어 예문, 번역, 예문 듣기.
- 카드를 누르면 0.3초 뒤집는다. `몰라요`는 `flagged_unknown`, `알아요`는 일반 배치로 S6 큐에 반영한다.
- 예문이 없는 단어는 이 화면에 들어오지 않는다.

### S6 퀴즈

- 공통: 진행바, 종료 X, 문제 영역, 선택/입력, B·C 유형의 힌트.
- 유형 A(stage 0~1): 영어 단어와 듣기, 한국어 뜻 4지선다.
- 유형 B(stage 2~3): 예문 빈칸, 번역, 같은 품사·레벨의 영어 보기 4개.
- 유형 C(stage 4~5): 뜻·품사·번역, 글자 수 밑줄, 철자 입력 및 Enter 제출.
- 정답은 초록 후 0.8초 자동 진행. 오답은 빨강·흔들림·정답 공개 후 `다음`으로 진행한다.
- 오답 단어는 세션 끝에 한 번만 재출제한다.
- B 힌트는 보기 2개 제거, C 힌트는 최대 2글자 공개다. 힌트 정답은 단계를 올리지 않는다.
- 철자는 소문자·앞뒤 공백을 무시한다. 편집거리 1이면 `거의 맞았어요`지만 오답이다.
- 답안 전송 실패는 로컬 큐에 보관하고 재연결 때 전송한다.

### S7 세션 결과

- 정답률, 정답률별 자체 캐릭터, 학습 단어 수, 연속 학습일, 틀린 단어 최대 10개를 보여준다.
- `틀린 단어 복습하기`로 이번 오답만 S6에 넣는다. 오답이 없으면 `전부 맞혔어요!`와 홈 버튼만 보여준다.
- 단어 행은 S9 상세를 연다.

### S8 오답노트

- `틀린 횟수순 / 최근순`, 단어·뜻·오답 횟수 리스트, `이 단어들만 복습`을 제공한다.
- 대상은 `wrong_count > 0 && stage < 4`, 복습은 상위 20개다. 행은 S9를 연다.

### S9 단어 상세 바텀시트

- 단어, 품사, 뜻, 예문·번역·듣기, 단계 n/5, 다음 복습일, 정답·오답 횟수를 보여준다.
- `모름으로 표시`는 stage 0으로 되돌린다. 아래 스와이프로 닫는다.

### S10 말하기 홈

- 제목과 `오늘 대화 n/40턴`, `오늘의 단어 3개로 대화` 토글과 단어 칩을 표시한다.
- `내가 만든 상황으로 연습`과 기본 8개 시나리오(카페, 입국심사, 호텔, 식당 예약, 길 묻기, 스몰토크, 면접, 자유 대화)를 제공한다.
- 최근 대화 3개는 S13 읽기 모드로 연다. 일일 한도 도달 시 시작 카드를 비활성화한다.

### S11 상황 만들기

- 최대 200자 상황 입력, 난이도 1~5 칩, 하단 `대화 시작`을 제공한다.
- 입력이 없으면 비활성화한다. 서버가 역할·설명·시스템 프롬프트를 생성·저장하고 S12로 간다.

### S12 대화

- 상단 뒤로, 시나리오 제목, 종료, 오늘의 단어 칩 3개, 속도 0.8/1.0과 AI 텍스트 숨김 설정을 둔다.
- 중앙은 AI/사용자 말풍선, 다시 듣기, 교정 존재 점을 표시한다. 하단은 말하기/타이핑 전환과 80px 마이크 버튼이다.
- 마이크는 최대 30초 녹음하며 재탭 또는 시간 초과로 전송한다. 연속 대화 모드는 발화 후 침묵을 감지해 전송하고 AI TTS가 끝나면 다시 청취한다. 처리 중에는 점 3개를 표시한다.
- 기본은 STT 결과 자동 전송, 설정 시 수정 후 전송한다. 직전 사용자 말풍선 길게 누르기로 직전 턴을 취소·재시도한다.
- AI는 2문장 이하로 답하고 대화를 질문으로 이어간다. 교정 내용은 종료 후 S13에서만 공개한다.
- 목표 단어는 사용 시 체크된다. AI는 목표 단어를 먼저 말해 주지 않는다.
- 3턴 미만 종료는 요약하지 않는다. 40턴 한도, 권한 거부, STT 실패, 응답 재시도를 처리한다.

### S13 대화 요약

- 턴 수, 목표 단어 사용 여부·SRS 반영, 자연스러운 표현 교정 최대 5개, 오늘 표현 3개를 표시한다.
- 교정 카드는 원문 취소선, 교정문, 한국어 설명, 듣기, `따라 말하기`를 제공한다.
- 따라 말하기는 STT 단어 일치율 80% 기준으로 성공·재시도를 표시하고 AI 턴 1회로 센다.
- 표현은 단어장에 phrase·stage 0으로 추가할 수 있다.

### S14 내 기록

- 연속 학습일, stage 4 이상 누적 단어, 최근 7일 평균 정답률 카드 3개를 보여준다.
- 최근 7일 학습 수 막대그래프와 목표선, 오답노트·설정 메뉴를 제공한다.

### S15 설정

- 새 단어 수 5/10/15/20, 복습 상한 20/30/50, TTS 0.8/1.0, 소리, 자동 재생, 음성 자동 전송, 목표 단어 사용을 편집한다.
- 일일 AI 한도는 읽기 전용이다. 레벨 재시험과 2단계 데이터 초기화를 제공한다.

## 4. 학습 규칙

### 학습 큐

1. KST 오늘 기준 복습 예정 단어를 `next_review_at` 오름차순으로 `review_cap`개 선택한다.
2. 현재 레벨의 미학습·예문 보유 단어를 `daily_new_count`개 선택한다. 부족하면 한 단계 위에서 채운다.
3. 새 단어 카드 → 새 단어 A 퀴즈 → 단계별 복습 퀴즈 순서다.
4. 세션 시작 응답에 새 단어와 전체 퀴즈 큐를 담아 학습 중 추가 조회를 피한다.

### 단계 SRS

이 기획서의 알고리즘은 FSRS가 아니라 명시적 stage 0~5 SRS다. 기존 `ts-fsrs` 구현은 이 명세와 다르므로 교체하거나 제품 결정을 문서로 바꿔야 한다.

```text
정답: stage + 1 (최대 5)
오답: stage - 2 (최소 0), 다음 날
힌트 정답: stage 유지
정답 간격: [1, 1, 3, 7, 14, 30]일
stage 5 무힌트 정답: mastered, 60일 뒤 점검
```

모든 시점은 Asia/Seoul 자정 기준 날짜로 저장한다. 목표 단어를 교정 없이 정확히 사용한 경우에도 정답 경로를 적용하되 하루 한 번만 반영한다.

### 연속 학습일

daily 또는 review 세션을 하루 한 개 이상 끝내면 `daily_stats`의 날짜 행을 만든다. 오늘 학습하지 않았으면 어제부터, 학습했으면 오늘부터 날짜가 끊길 때까지 거꾸로 센다. 하루를 건너뛰면 0이다.

## 5. AI 말하기 계약

- 오디오: mp4/AAC 또는 webm, 최대 30초. `gpt-4o-mini-transcribe`로 STT한다.
- 대화: 시나리오 프롬프트, 최근 10턴, 최신 발화를 Haiku 계열 모델에 보내 JSON만 받는다.
- JSON: `{ reply, usedWords, correction }`. 답변은 두 문장 이하, 반복 금지, 이해 실패 시 짧게 되묻고 질문으로 끝낸다.
- 교정: 한 턴에 명백한 문법·단어 오류 한 개 이하. 대화 중에는 `hasCorrection`만 클라이언트에 전달한다.
- 요약: 종료 시 교정을 합쳐 최대 5개와 표현 3개를 만든다.
- 서버는 `daily_stats.ai_turns`로 40턴 기본 한도를 강제하며 초과 시 429를 반환한다.
- STT의 자연 보정 때문에 발음 점수로 표현하지 않는다.
- API 키는 서버 환경변수에만 둔다.

## 7. API 표면

- Level: `GET /level-test/questions`, `POST /level-test/submit`.
- Study: `POST /study/sessions`, `POST /study/answers`, `POST /study/sessions/:id/finish`.
- Review: `GET /review/due`, `GET /review/wrong-notes`, `PATCH /user-words/:wordId`.
- Stats/settings: `GET /stats/summary`, `GET /stats/weekly`, `GET/PUT /settings`.
- Speaking: `GET /speaking/scenarios`, `POST /speaking/scenarios/custom`, `POST /speaking/sessions`, `POST /speaking/sessions/:id/turn`, `POST /speaking/sessions/:id/transcribe`, `DELETE /speaking/sessions/:id/turns/last`, `POST /speaking/sessions/:id/finish`, `POST /speaking/repeat-check`, `POST /speaking/phrases`.
- 오류 응답은 `{ code, message }`, AI 한도는 429, 서버 오류는 5xx다.

## 8. 디자인·접근성 계약

- 색: 배경 `#FAFAF7`, 카드 `#FFFFFF`, 텍스트 `#1A1A1A`, 보조 `#6B7280`, 선 `#E5E7EB`, 포인트 `#4F46E5`, 정답 `#16A34A`, 오답 `#EF4444`, 스트릭 `#F59E0B`.
- Pretendard 실패 시 시스템 폰트. 단어 32 Bold, 제목 24 Bold, 본문 18, 보조 14.
- 4px 간격 체계, 카드 radius 20, 버튼 radius 16, 카드에만 약한 그림자.
- 주 버튼 56px, 모든 터치 영역 최소 44px, safe-area 반영.
- 카드 뒤집기 0.3초, 오답 흔들림 0.2초, 로딩은 스켈레톤.
- 색·간격은 `theme/tokens.ts`에서만 가져온다. 캐릭터는 자체 아이콘형 한 종을 쓴다.

## 9. 구현 및 검수 상태

- `apps/web`에 S1–S15 화면과 서버 API 연결을 구현했다. API가 없으면 실제 로컬 단어 학습과 기록 계산을 제공하며, AI 말하기는 서버 연결이 필요하다고 표시한다.
- `apps/server`에 레벨 테스트, stage 0–5 SRS, 학습 세션, 오답, 설정, 통계, 8개 상황과 대화 API를 구현했다. 서버 단위 테스트와 임시 HTTP 검사를 통과했다.
- 녹음은 `MediaRecorder`에서 서버 OpenAI STT로 전달되며 파일을 저장하지 않는다. 실제 iPhone 마이크/음성 품질은 검증 전이다.
- SQLite 저장소는 적용했으나 현재 `app_state` 한 행에 상태를 보관한다. 기획서의 개별 테이블은 아직 적용하지 못했다. 콘텐츠는 자체 작성 126개이며 그중 비즈니스 54개에 구어체·문어체 비교가 있다. Mac mini 설치, Tailscale, 실제 AI 키, 비용 계측, 3,000단어 콘텐츠는 출시 차단점이다.
- 상세 판정은 `docs/feature-parity.md`, `tests/acceptance-plan.md`, `docs/architecture.md`를 따른다.
