# 개인 영어 학습 루프

## 현재 동작

1. CEFR A1–C2 어휘 24문항으로 **임시 학습 시작점**을 정한다. 문항은 B1/B2부터 섞어 내고 보기 정답 위치를 균형 배치한다. 이 결과는 종합 CEFR 인증이나 IELTS 점수가 아니다.
2. 선택 레벨 가까이의 새 단어와 복습 예정 단어를 낸다. 첫 답안만 정답률·SRS 단계에 반영하고, 틀린 단어는 같은 세션 끝에 다시 연습한다. 오답노트는 `틀린 횟수 > 0 && stage < 4`인 단어를 보여준다.
3. 최근 30일 첫 답안에서 CEFR·품사별 약한 묶음을 찾고, 실제 말하기 교정 문장을 함께 보여준다. 표본이 5개 미만이면 약점이라고 단정하지 않는다.
4. AI 말하기 서버가 연결되면 최근 오답 묶음과 교정 사례를 대화 문맥에 넣어 자연스러운 재연습 질문을 유도한다. 세 턴 이상 대화를 마치면 잘한 점·집중할 점·다음 말하기 과제를 요약한다. 교정은 사용자가 실제로 한 말에 근거한다.
5. 비즈니스 영어 54개 항목은 구어체와 문어체 예문을 나란히 보여 주고 한국어로 용법 차이를 설명한다. 현재 전체 콘텐츠는 126개 자체 작성 시드다.

## 데이터 기준

- 연속 학습일: 한국 날짜로 실제 단어를 학습한 날이 오늘 또는 어제부터 연속된 횟수. 새 계정은 0일.
- 7일 정답률: 최근 한국 달력 7일 동안의 첫 답안 정답 수 / 첫 답안 수. 답안이 없으면 화면에는 `—`를 보여 준다.
- 암기 단어: SRS `stage >= 4`인 단어 수.
- 오답노트: 누적 오답 횟수가 1 이상이고 아직 `stage < 4`인 단어. 이후 정답을 맞혀도 stage 4 전까지 남는다.
- 서버 미연결: 단어 학습 기록을 해당 기기 브라우저에 저장한다. Mac mini 기록과 자동 병합하지 않는다. 설정에서 로컬 JSON 백업·복원을 제공하므로 기기 변경·브라우저 데이터 삭제 전에 파일을 안전하게 보관해야 한다.

## 남은 제품 작업

실제 학습 콘텐츠를 검수하며 3,000개 목표로 늘리고, 학습자별 서술형 문장·발음·쓰기 증거를 추가해야 한다. 현재 AI 개인화는 퀴즈 오답과 대화 교정에 한정된다. 실제 모델 품질, 코칭의 교육적 타당도, 말하기 난이도 조절, iPhone 마이크/TTS, 오프라인 기록의 서버 병합, 장기 학습 효과는 아직 검증되지 않았다. IELTS 밴드를 표시하려면 공식 시험 구성요소를 평가하는 별도 절차가 필요하다.
