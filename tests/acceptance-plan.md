# 출시 수용 테스트 계획

각 마일스톤은 아래 필수 테스트가 모두 통과하고 증거(명령 출력, 브라우저 결과, iPhone 화면 기록)가 남기 전까지 완료로 표시하지 않는다. 단순 빌드 성공은 화면·데이터·실기기 성공을 대신하지 않는다.

## M1 기반·시드·접속

### 자동 테스트

- `M1-01`: 깨끗한 체크아웃에서 고정 lockfile로 web·server 의존성을 설치한다.
- `M1-02`: web·server TypeScript가 `any` 없이 타입 검사와 프로덕션 빌드를 통과한다.
- `M1-03`: SQLite 마이그레이션을 빈 DB에 적용하고 재적용해도 실패하지 않는다.
- `M1-04`: seed 후 words에 레벨 1~5, 기본 시나리오 8개, settings 기본값이 존재한다.
- `M1-05`: 콘텐츠 검증은 예문 6~16단어, 원형 단어 포함, 필수 필드를 검사한다. 실패 항목은 노출 대상에서 제외한다.
- `M1-06`: API 키·토큰·`.env` 값이 Git 추적 파일과 클라이언트 번들에 없다.

### 실기기 게이트

- `M1-IOS-01`: 지정 iPhone/iOS에서 Tailscale HTTPS 주소가 Safari와 홈 화면 PWA에서 열린다.
- `M1-IOS-02`: 마이크 권한 허용·거부·재허용 안내가 정확하다.
- `M1-IOS-03`: 30초 녹음을 mp4/AAC로 만들고 서버가 받아 STT할 수 있다.
- `M1-IOS-04`: 0.8x·1.0x TTS가 무음 모드, 스피커, 이어폰에서 기대대로 작동한다.
- `M1-IOS-05`: PWA 종료·재실행과 네트워크 단절·복구를 확인한다.

## M2 학습 핵심 S4~S6

- `M2-01`: daily 세션은 KST 오늘 기준 예정 복습을 상한만큼 먼저 선택하고 현재 레벨의 미학습 새 단어를 설정 개수만큼 선택한다.
- `M2-02`: 새 단어 부족 시 한 단계 위에서 채우며 예문 없는 단어는 선택하지 않는다.
- `M2-03`: 새 단어가 있으면 S5를 거쳐 S6, 없으면 바로 S6으로 간다.
- `M2-04`: S5의 `몰라요` 단어가 퀴즈 앞쪽에 배치되고 카드·예문 TTS가 설정 속도를 따른다.
- `M2-05`: stage 0~1=A, 2~3=B, 4~5=C 유형이다.
- `M2-06`: B 오답은 같은 레벨·품사 우선, C는 대소문자·외곽 공백을 무시하며 편집거리 1은 오답이다.
- `M2-07`: 오답은 한 번만 큐 끝에 재출제된다.
- `M2-08`: 힌트 사용 정보가 저장되고 네트워크 실패 답안은 로컬 큐에서 재전송된다.
- `M2-09`: 모든 진행 화면의 X는 푼 데까지 저장하고 홈으로 간다.

## M3 SRS·복습 S7~S9

### `calcNext` 필수 단위 테스트

| Case | 입력 | 기대 |
| --- | --- | --- |
| SRS-01 | stage 0 정답 무힌트 | stage 1, +1일 |
| SRS-02 | stage 1 정답 무힌트 | stage 2, +3일 |
| SRS-03 | stage 3 정답 무힌트 | stage 4, +14일 |
| SRS-04 | stage 5 정답 무힌트 | stage 5, mastered, +60일 |
| SRS-05 | stage 4 오답 | stage 2, +1일 |
| SRS-06 | stage 1 오답 | stage 0, +1일 |
| SRS-07 | stage 3 힌트 정답 | stage 3, +7일 |
| SRS-08 | KST 23:59와 다음 날 00:01 | 각각 KST 자정 기준 날짜로 계산 |

- `M3-01`: S7 정답률·단어 수·스트릭·오답 목록이 세션 로그와 일치한다.
- `M3-02`: 오답 없는 결과와 오답 있는 결과의 주 버튼이 다르다.
- `M3-03`: S8 정렬과 상위 20개 복습 큐가 정확하다.
- `M3-04`: S9 reset이 stage 0과 다음 복습일을 갱신한다.
- `M3-05`: 같은 말하기 목표 단어는 하루 한 번만 S 정답으로 반영된다.

## M4 레벨 테스트·통계·설정 S1~S3, S14~S15

- `M4-01`: 최초 진입에 레벨 테스트가 열리고 건너뛰면 레벨 1이다.
- `M4-02`: 각 레벨 4문항이며 같은 실행에서 중복 단어가 없다.
- `M4-03`: 선택 중 정오를 공개하지 않고 중단 후 재진입하면 1번부터다.
- `M4-04`: 3개 이상 맞힌 가장 높은 레벨, 모두 미달이면 레벨 1이다.
- `M4-05`: 오늘/어제 연속 학습일과 하루 결석 초기화를 KST 날짜로 테스트한다.
- `M4-06`: 최근 7일 평균 정답률·학습 수·mastered 개수가 DB와 일치한다.
- `M4-07`: 모든 설정 값이 API·UI·다음 세션에 반영된다.
- `M4-08`: 데이터 초기화는 2단계 확인 후에만 실행되고 복구 불가 경고가 명확하다.

## M5 AI 말하기·단어 연동 S10, S12, S13

### 서버 계약

- `M5-01`: STT는 mp4/AAC와 webm을 받고 30초·크기 제한을 서버에서 거부한다.
- `M5-02`: LLM 출력은 스키마 검증을 통과한 JSON만 저장한다. 파싱 실패는 재시도 후 사용자 오류로 바꾼다.
- `M5-03`: 최근 10턴만 전달하며 target word를 AI가 먼저 말하지 않는다.
- `M5-04`: 답은 최대 두 문장, 질문·쉬운 프롬프트로 끝나고 최신 사용자 문장을 앵무새처럼 반복하지 않는다.
- `M5-05`: 일일 40턴을 서버에서 원자적으로 세고 초과 요청은 429다.
- `M5-06`: 직전 턴 삭제가 마지막 사용자·AI 메시지와 해당 usedWords를 함께 되돌린다.
- `M5-07`: 3턴 미만은 요약하지 않고, 5턴 이상은 교정 최대 5개·표현 3개를 생성한다.
- `M5-08`: 교정 없는 정확한 목표 단어만 SRS에 반영한다.

### 대화 품질 회귀 세트

최소 30개 고정 입력을 수준·시나리오별로 유지한다. 응답은 수작업 기준과 자동 조건을 함께 검사한다.

- 단순 정상 문장, 명백한 문법 오류, 모호한 음성, 침묵, 욕설·민감 입력, 긴 입력, target word 활용형, target word 미사용.
- 응답 길이, 질문 포함, 반복 금지, correction 최대 1개, `usedWords` 보수 판정, CEFR 난이도를 평가한다.

### iPhone 대화 게이트

- `M5-IOS-01`: 10분 또는 20턴 대화를 진행하며 녹음 시작·종료·업로드·TTS·다음 턴이 반복된다.
- `M5-IOS-02`: 전화·Siri·잠금·백그라운드·이어폰 전환 뒤 안전하게 복구하거나 명확히 중단한다.
- `M5-IOS-03`: AI 텍스트 숨김, TTS 속도, 자동 재생, 타이핑 모드를 각각 확인한다.
- `M5-IOS-04`: 잘못 인식된 직전 턴 취소·다시 말하기가 서버 상태와 동기화된다.
- `M5-IOS-05`: 권한 거부 시 타이핑으로 전체 대화를 완료할 수 있다.

## M6 사용자 상황·공통 품질

- `M6-01`: 1~200자 사용자 상황이 역할·설명·프롬프트로 생성되고 목록에 남는다.
- `M6-02`: 모든 S1~S15에 정상·로딩·빈 상태·권한 거부·네트워크 오류가 정의돼 있다.
- `M6-03`: API 5xx는 상단 `연결이 불안정해요`와 재시도를 제공하며 사용자 입력을 잃지 않는다.
- `M6-04`: 모든 터치 대상 44px 이상, 하단 고정 버튼은 safe area를 피한다.
- `M6-05`: 200% 확대, VoiceOver 탐색, 키보드 조작, 색상 대비를 확인한다.
- `M6-06`: 서비스 워커 업데이트 후 오래된 클라이언트와 API 스키마 충돌을 처리한다.
- `M6-07`: DB 백업을 만들고 새 서버에서 복원해 기록·설정·대화를 대조한다.

## 비용·보안 게이트

- `OPS-01`: 서버 로그에 API 키, 전체 오디오, 민감 헤더가 남지 않는다.
- `OPS-02`: 프런트 번들에서 OpenAI·Anthropic 키 패턴이 발견되지 않는다.
- `OPS-03`: Tailscale 계정 밖 기기에서 서버에 접근할 수 없다.
- `OPS-04`: 모델별 토큰·STT 분·오류·재시도를 일별 기록하고 월 예상 비용을 표시한다.
- `OPS-05`: 보수적 사용량 3배에서도 월 10,000원 이하임을 실제 청구 단가로 계산한다.
- `OPS-06`: 일일 턴 한도와 요청 크기 제한은 클라이언트가 아니라 서버가 강제한다.

## 출시 판정

프로덕션 완료로 부르려면 다음이 모두 필요하다.

1. S1→S7의 첫 실행·학습 핵심 흐름이 실제 서버와 끊김 없이 완료된다.
2. S10→S13의 5턴 이상 대화, 요약, 따라 말하기, 목표 단어 반영이 완료된다.
3. `calcNext` 필수 테스트와 서버·웹 빌드가 통과한다.
4. 지정 iPhone에서 HTTPS PWA, 마이크, TTS, 복구 테스트가 통과한다.
5. SQLite 백업·복원과 비용 상한을 증명한다.
6. P0/P1 결함이 0개이며 문서의 미검증 항목이 실제 증거로 닫힌다.

현재 Vercel의 단일 페이지 프로토타입은 이 출시 조건을 충족하지 않는다.
